# プロダクト概要（TLINY）

TLINY は学校バザーをデジタル化し、安全・効率的な運営を実現する Web アプリ。生徒・保護者・教職員がオンラインで出品・購入し、QR 受け渡しとキャッシュレス決済（Stripe）でスムーズな体験を提供する。

## コアバリュー
- 安全な決済と現金管理の撤廃
- リアルタイムな在庫・売上可視化
- 受け渡しの効率化（QR チケット）
- 学校運営に適した簡潔な管理 UX

## 主要機能
- ユーザー: 商品閲覧/検索、カート、Stripe 決済、注文履歴、QR 受け渡し
- 管理者: イベント/商品/在庫/スタッフ管理、売上ダッシュボード、QR スキャン
- 分析: 商品別/日別売上、在庫、顧客動向

## ターゲット利用シナリオ
- 文化祭/学校祭などの一時的なバザー運営
- PTA 主催の販売イベント
- 学校内の期間限定ショップ

## 成功指標（例）
- 受け渡し待ち時間の短縮（中央値 50% 減）
- 在庫ロス率の低下（10%→5% 未満）
- 返金/トラブルの件数削減

## 制約/前提
- Web アプリ（Flutter Web）を主対象
- Firebase（Auth/Firestore/Storage/Functions/Hosting）
- Stripe によるカード決済（秘密鍵は Functions 側のみ）

## 今後の拡張余地
- PWA（オフライン簡易対応、ホーム画面追加）
- 通知（Web Push/アプリ内）
- 拡張レポート（CSV 出力、保護者向け領収書強化）
